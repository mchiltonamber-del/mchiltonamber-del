# User Stories

## User Story 1: View Portfolio

As a visitor, I want to view the portfolio owner's information so that I can learn about their background and skills.

**Acceptance criteria:**
- The homepage displays the portfolio owner's name and introduction.
- Visitors can view the owner's skills, projects, and background information.

## User Story 2: View Projects

As a visitor, I want to view the portfolio owner's projects so that I can understand their experience and abilities.

**Acceptance criteria:**
- The portfolio displays a list of projects with their titles and descriptions.
- Visitors can open project links when links are provided.

## User Story 3: Contact the Portfolio Owner

As a visitor, I want to find the portfolio owner's contact information so that I can get in touch with them.

**Acceptance criteria:**
- The portfolio provides contact information or a contact section.
- Visitors can access the provided email address or contact links.
